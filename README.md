# Apps perso pour Umbrel

Catalogue d'apps communautaire pour umbrelOS.

Ajout : App Store → ⋯ → Community App Stores → coller l'URL de ce dépôt.

- **Home Hub** : tableau de bord maison (lumières, enceintes, machines, NAS) branché sur Home Assistant.
  Après installation, copier sa configuration dans `~/umbrel/app-data/xen-home-hub/data/config.toml`
  puis redémarrer l'app.
